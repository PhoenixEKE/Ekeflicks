# Portail producteur EkeFlicks

Application Flutter destinée aux producteurs : tableau de bord, catalogue, ajout de
films/séries, finance, réclamations et profil. Les écrans sont présents mais aucun
client API n'est encore intégré ; les parcours de production restent donc à relier et
à démontrer de bout en bout.

# Démarrage

Voir le [guide des environnements](../docs/ENVIRONNEMENTS.md), puis :

```bash
flutter pub get
flutter gen-l10n
flutter analyze
flutter test
flutter run -d chrome
```

Le détail des travaux restants est suivi dans l'[audit général](../docs/AUDIT_GENERAL.md).
