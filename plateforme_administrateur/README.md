# Portail administrateur EkeFlicks

Application Flutter destinée à l'administration des utilisateurs, producteurs,
contenus et réclamations. Plusieurs écrans utilisent encore des données d'exemple et
aucun client API n'est intégré. Le package porte encore le nom technique
`plateforme_producteurs` ; son renommage devra inclure les identifiants natifs.

## Démarrage

Voir le [guide des environnements](../docs/ENVIRONNEMENTS.md), puis :

```bash
flutter pub get
flutter gen-l10n
flutter analyze
flutter test
flutter run -d chrome
